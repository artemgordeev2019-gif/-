# zefir — сайт студии маникюра и педикюра

Редизайн сайта для студии маникюра и педикюра (Instagram: `zefir.manicure`,
`zefir.beautystudio`). Вместо экрана записи услуг у стороннего сервиса —
собственный одностраничник с айдентикой, портфолио, прайсом и командой.

## Айдентика

Структура — editorial-референс (крупный uppercase-заголовок, фото в рамке
с уголками-«видоискателем»), но палитра — тёмная и премиальная: без бежевого
и светлых фонов, глубокий сливовый почти-чёрный, золото как «металл»,
виолет как цвет бренда, вино — акцент для глубины. Вся анимационная жизнь
(«живые» кнопки, искры, полароиды) осталась — это всё ещё zefir.

| Элемент | Решение |
| --- | --- |
| Палитра | Глубокий сливовый почти-чёрный фон (`--cream`/`--cream-deep`, названия токенов остались от прошлой версии — значения теперь тёмные), тёплый айвори `--ink` для текста. Золото (`--gold`) — премиальный акцент и «металл» рамок, виолет — бренд, вино (`--wine`) — глубина в градиентах |
| Уголки-рамки | Реиспользуемый `.frame` + 4 `<i class="corner">` теперь золотые — «видоискатель» на фото хиро и в триптихе деталей читается как золотая окантовка |
| Полароиды | Тёмная «музейная» подложка вместо белой бумаги, скотч — золотистый вместо белого: по сути тот же кадр в рамке, но премиальнее |
| Заголовки | Хиро — `Commissioner` 700 uppercase (редакционный, «плакатный» блок), курсивный акцент и заголовки секций — `Cormorant` italic/normal |
| Текст/интерфейс | `Commissioner` — геометричный гуманистический sans |
| Логотип | Настоящий логотип студии, воссозданный инлайновым SVG: монограмма «Z» в каллиграфическом овале с завитками + две золотые звёздочки, ниже `Zefir` вразрядку и подпись. Компактный вариант в шапке, полный — в футере, «Z» контуром — фавикон |

`--rose-ink`/`--gold-ink` (введены для читаемости акцентов на кремовом фоне
в прошлой версии) теперь просто алиасят `--orchid`/`--gold` — на тёмном фоне
яркие акценты сами по себе проходят контраст как текст, отдельный
затемнённый вариант не нужен, но переименовывать каждое использование не
пришлось. Обе гарнитуры — вариативные (variable), подключены в двух файлах
на семью (`latin` + `cyrillic`); смена палитры не потребовала новых файлов
шрифтов — только перетасовку CSS-токенов.

## Что внутри

| Файл | Что это |
| --- | --- |
| `src/index.html` | Исходная страница: маркер `/*@FONTS@*/` вместо шрифтов, маркеры `@IMG` — слоты под фото |
| `build/build.py` | Сборка: вшивает шрифты и фото в страницу как data-URI |
| `build/*.woff2` | Cormorant + Commissioner, latin/cyrillic, скачаны с Google Fonts |
| `references/` | «Вход» для фото — файлы отсюда попадают в слоты (см. `references/README.md`) |
| `dist/index.html` | Собранная самодостаточная страница — не тянет ни одного внешнего ресурса |
| `DESIGN-PROMPT.md` | Промт-хендовер: по нему дизайн можно воспроизвести или продолжить с нуля |

## Сборка

```sh
python3 build/build.py
```

## Как добавить фото

Положите файлы в `references/` с именами `hero`, `detail-1..3`,
`work-1..6`, `master-liza`, `master-tanya` (любое расширение картинки) и
запустите сборку — фото сами встанут в слоты, HTML править не нужно.
Класть можно хоть один файл: незаполненные слоты останутся с
плейсхолдером. Подробности и пропорции — в `references/README.md`.

## Что уже реальные данные, а что — плейсхолдер

- **Прайс-лист** — реальные позиции и цены из текущей записи студии
  (маникюр, педикюр). Три строки без видимой цены в исходнике отмечены
  «уточняйте».
- **Instagram-ссылки** (`@zefir.manicure`, `@zefir.beautystudio`) — реальные.
- **Все фото (12 слотов)** — пока плейсхолдеры: реальных файлов с
  кадрами получить не удалось (в переписке картинки видны, но на диск
  не попадают, а `instagram.com` закрыт сетевой политикой). Слоты
  размечены и ждут файлов в `references/` — см. раздел «Как добавить
  фото» выше.
- **Мастера** — реальные: Лиза (топ-мастер, руководитель студии, стаж 9+
  лет) и Татьяна (мастер маникюра, стаж 4 года), имена/стаж/специализации
  взяты из хайлайта студии «Наши мастера». Вместо портретов — монограмма,
  до появления `master-liza.*` / `master-tanya.*` в `references/`.
- **Отзывы** — примеры формата (5 звёзд + цитата + имя). Замените на
  реальные отзывы клиенток.
- **Советы** (`#tips`) — темы реальные, взяты из постов студии в
  Instagram («Табу перед маникюром», «Почему появляются поломки»,
  «Сниму сама!»), но тексты под ними — общие проверенные рекомендации,
  а не дословный пересказ подписей: те были обрезаны на скринах кнопкой
  «ещё», полного текста не было видно.
- **Адрес, часы работы, телефон** — в блоке контактов оставлены как
  «уточняйте в Direct»: реальных данных не было, но раздел уже свёрстан —
  просто впишите текст на место плейсхолдера.

## Проверено

Chromium, без консольных ошибок, ширины 390 / 834 / 1440:

- нет горизонтального переполнения на любой ширине;
- мобильное меню и переключатель вкладок «Маникюр / Педикюр» работают
  с клавиатуры и по ARIA (`role="tablist"`, `aria-selected`);
- `prefers-reduced-motion` — фон-блобы, scroll-reveal, wobble/breathe/
  sparkle-анимации отключаются, контент остаётся сразу видимым;
- заголовок первого уровня один (хиро), дальше — `h2` по секциям,
  `h3` — только внутри карточек;
- WCAG-контраст всех пар текст/фон посчитан вручную (формула
  относительной яркости) — минимум 6.95:1 при требуемых 4.5:1,
  у большинства пар 8–17:1;
- `<figure>` (полароиды, рамка хиро, триптих) получил явный `margin: 0` —
  без этого сброса UA-стиль браузера (`margin: 1em 40px`) на узких экранах
  схлопывал ширину карточек до считанных пикселей.

## Источник дизайн-интеллекта

Палитра, пара шрифтов и структура страницы (hero → portfolio → price →
team → social proof → CTA) подобраны через локальный поиск скилла
[`ui-ux-pro-max`](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)
(`--domain color/product/typography/google-fonts/ux/gsap`), затем адаптированы
под бренд-бриф вручную.
