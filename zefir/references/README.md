# Референсы и фото — zefir

Эта папка — «вход» для картинок. Положите сюда файлы с нужными именами,
запустите сборку — и фото сами встанут на свои места на сайте. Ничего
править в HTML руками не нужно.

## Как добавить фото

1. Сохраните кадры из Instagram себе на телефон/компьютер.
2. Переименуйте по таблице ниже и положите файлы **в эту папку**.
3. Выполните из корня проекта:

   ```sh
   python3 build/build.py
   ```

Скрипт напечатает, что нашёл, а что осталось плейсхолдером:

```
index.html -> dist/index.html  445 KB
  hero           — hero.jpg (10 KB)
  work-1         — placeholder (no references/work-1.*)
  ...
```

Класть можно **сколько угодно файлов, хоть один** — незаполненные слоты
останутся с плейсхолдером, страница в любом случае собирается и работает.

## Имена файлов

Расширение любое из: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, `.gif`.

| Файл | Куда попадёт | Пропорции |
| --- | --- | --- |
| `hero.jpg` | Большое фото в первом экране, в рамке с золотыми уголками | 16:10, горизонтальное |
| `detail-1.jpg` | Триптих под кнопками — плитка «цвет» | 3:4, вертикальное |
| `detail-2.jpg` | Триптих — плитка «форма» | 3:4, вертикальное |
| `detail-3.jpg` | Триптих — плитка «уход» | 3:4, вертикальное |
| `work-1.jpg` … `work-6.jpg` | Шесть полароидов в разделе «Портфолио» | 1:1, квадрат |
| `master-liza.jpg` | Портрет Лизы в карточке мастера | 1:1, лицо по центру |
| `master-tanya.jpg` | Портрет Татьяны в карточке мастера | 1:1, лицо по центру |

Пропорции — рекомендация, не требование: любое фото впишется по
`object-fit: cover` (обрежется по центру до нужной формы). Но если кадр
сильно другой пропорции, по краям срежется больше, чем хотелось бы.

## Размер файлов

Фото вшиваются в HTML как base64, поэтому страница растёт примерно на
⅓ больше веса самих файлов. Ориентир: **до ~300 КБ на фото**, иначе
страница станет тяжёлой. Если исходники крупные, уменьшите их до
~1200 px по длинной стороне перед тем, как класть сюда.

## Подписи (alt)

У каждого слота уже прописан осмысленный `alt` — он берётся из разметки
`src/index.html` (маркеры `<!--@IMG:слаг|описание-->`), менять ничего не
нужно. Если формулировка не нравится, поправьте текст после `|`.

## Если файлы не удаётся передать

В переписке картинка, вставленная прямо в текст сообщения, до диска не
доходит — её видно только «глазами». Рабочие варианты: приложить файлом
через скрепку, дать прямую ссылку на файл на любом хостинге (кроме
Instagram — он заблокирован сетевой политикой), либо добавить файлы в эту
папку через git.

## Референсы стиля

Сюда же можно класть картинки-ориентиры (чужие сайты, настроение,
палитра) — просто с любым другим именем, не совпадающим с таблицей выше.
Сборка их проигнорирует, а при обсуждении на них можно ссылаться.
