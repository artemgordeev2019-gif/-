# Мастерская Гордеева — сайт

Самодостаточная страница: заказы, личные задачи, финансы и загрузка.
Открывается с телефона и с компьютера по одной ссылке, работает без сборки
и без сервера — это статические файлы.

## Файлы

| Файл | Что это |
| --- | --- |
| `index.html` | Вся страница: разметка, стили, логика |
| `data/state.json` | Общие стартовые данные — их видят все, кто открыл ссылку |
| `manifest.webmanifest` | Иконка и имя при установке «на экран Домой» |
| `sw.js` | Кэш оболочки: страница открывается и без сети |
| `icon.svg`, `icon-*.png` | Иконки для вкладки и для домашнего экрана |

## Как это работает с данными

При открытии страница берёт более свежее из двух: `data/state.json` с сервера
и копию в `localStorage` браузера. Всё, что вы меняете на странице, пишется в
`localStorage` — то есть остаётся **в этом браузере, на этом устройстве**.
Правки одного посетителя не видны другим и не уезжают на сервер.

Чтобы обновить то, что видят все: нажмите «Выгрузить JSON», положите
полученный файл в `data/state.json`, закоммитьте — при следующем открытии
страница подтянет новые данные (у тех, кто ничего не правил у себя локально).

## Локальный просмотр

```sh
python3 -m http.server 8000 --directory site
```

и открыть <http://localhost:8000>.

## Публикация

Ветку `main` публикует GitHub Actions (`.github/workflows/pages.yml`) в GitHub
Pages. Один раз нужно включить Pages: **Settings → Pages → Source: GitHub
Actions**. После этого каждый push в `main`, который трогает `site/`,
обновляет сайт.

## Проверено

Chromium, ширины 390 / 768 / 1440:

- нет горизонтального переполнения;
- в консоли чисто;
- светлая и тёмная тема;
- модалка нового заказа помещается в экран телефона;
- на тач-устройствах кнопки удаления видны без наведения.
